# เครื่องมือเก็บรวบรวมข้อมูล (ฉบับแก้ไข)

## ฉบับที่ 1 แบบประเมินประสิทธิภาพระบบเว็บแอปพลิเคชัน (สำหรับผู้เชี่ยวชาญ)

คำชี้แจง แบบประเมินฉบับนี้จัดทำขึ้นเพื่อประเมินประสิทธิภาพของระบบเว็บแอปพลิเคชันเพื่อการบริหารจัดการและตรวจสอบผลการดำเนินกิจกรรมนักศึกษา โปรดทำเครื่องหมาย ✓ ลงในช่องระดับคะแนนที่ตรงกับความคิดเห็นของท่านมากที่สุด (5 = มากที่สุด, 4 = มาก, 3 = ปานกลาง, 2 = น้อย, 1 = น้อยที่สุด)

### ตอนที่ 1 ข้อมูลทั่วไปของผู้เชี่ยวชาญ

1. ตำแหน่ง/ความเชี่ยวชาญ: ( ) นักวิเคราะห์ระบบ ( ) นักพัฒนาซอฟต์แวร์ ( ) ผู้ดูแลระบบฐานข้อมูล ( ) อาจารย์ผู้สอนด้านคอมพิวเตอร์ ( ) อื่น ๆ...........
2. ประสบการณ์การทำงานด้านเทคโนโลยีสารสนเทศ: ............. ปี

### ตอนที่ 2 การประเมินประสิทธิภาพของระบบเว็บแอปพลิเคชัน

| รายการประเมิน | 5 | 4 | 3 | 2 | 1 |
|---|---|---|---|---|---|
| **1. ด้านการทำงานของระบบ (Functional Requirement)** | | | | | |
| 1.1 ระบบสามารถตรวจสอบสิทธิ์และแยกการแสดงผลตามกลุ่มผู้ใช้งานได้ถูกต้อง | | | | | |
| 1.2 ระบบสามารถสร้างกิจกรรม กำหนดโควตา และสร้าง QR Code ได้ | | | | | |
| 1.3 ระบบสามารถบันทึกการเช็คชื่อเข้าร่วมกิจกรรมด้วย QR Code ร่วมกับ GPS และเซลฟีได้อย่างสมบูรณ์ | | | | | |
| 1.4 ระบบสามารถเทียบโอนและแยกแยะเงื่อนไขชั่วโมงกิจกรรม (ภาคปกติ/พิเศษ) ได้ | | | | | |
| **2. ด้านความถูกต้องของระบบ (Accuracy)** | | | | | |
| 2.1 ความถูกต้องของการบันทึกข้อมูลลงฐานข้อมูลและการเรียกดูข้อมูลย้อนหลัง | | | | | |
| 2.2 ความถูกต้องในการคำนวณและสรุปยอดชั่วโมงกิจกรรมสะสมของนักศึกษา | | | | | |
| 2.3 ความถูกต้องของการแสดงผลลัพธ์การอนุมัติและการสร้างเอกสารสรุปผลกิจกรรม (PDF) | | | | | |
| **3. ด้านความง่ายในการใช้งาน (Usability)** | | | | | |
| 3.1 การออกแบบส่วนติดต่อผู้ใช้งาน (User Interface) มีความเหมาะสม เข้าใจง่าย | | | | | |
| 3.2 ลำดับขั้นตอนการทำงานของระบบมีความต่อเนื่อง ไม่ซับซ้อน | | | | | |
| 3.3 ระบบมีการแจ้งเตือน (Error Message / Success Message) ที่ชัดเจน | | | | | |
| **4. ด้านความปลอดภัยของข้อมูล (Security)** | | | | | |
| 4.1 ระบบมีการป้องกันการเข้าถึงข้อมูลจากผู้ที่ไม่มีสิทธิ์ได้อย่างรัดกุม | | | | | |
| 4.2 ระบบมีการยืนยันตัวตนผ่านบัญชี Google ของมหาวิทยาลัยและจำกัดเฉพาะโดเมนที่กำหนดได้อย่างรัดกุม | | | | | |

## ฉบับที่ 2 แบบสอบถามความพึงพอใจ (สำหรับกลุ่มตัวอย่างผู้ใช้งาน)

คำชี้แจง แบบสอบถามฉบับนี้มีวัตถุประสงค์เพื่อประเมินความพึงพอใจในการใช้งานเว็บแอปพลิเคชันบริหารจัดการกิจกรรมนักศึกษา โปรดทำเครื่องหมาย ✓ ลงในช่องระดับคะแนนที่ตรงกับความเป็นจริงมากที่สุด (5 = มากที่สุด, 4 = มาก, 3 = ปานกลาง, 2 = น้อย, 1 = น้อยที่สุด)

> กลุ่มตัวอย่างของแบบสอบถามฉบับนี้ประกอบด้วยนักศึกษาสาขาวิชาวิทยาการคอมพิวเตอร์ อาจารย์ประจำกองพัฒนานักศึกษา และผู้แทนสภานักศึกษา รวม 28 คน (ดูหัวข้อ 3.1.2) — ข้อ 3-6 ในตอนที่ 1 จึงถามเฉพาะผู้ตอบที่เป็นนักศึกษาเท่านั้น

### ตอนที่ 1 ข้อมูลทั่วไปของผู้ตอบแบบสอบถาม

1. บทบาท: ( ) นักศึกษา ( ) อาจารย์ประจำกองพัฒนานักศึกษา ( ) ผู้แทนสภานักศึกษา
2. เพศ: ( ) ชาย ( ) หญิง ( ) อื่น ๆ
3. *(กรณีเป็นนักศึกษา)* คณะ: ..............................................................
4. *(กรณีเป็นนักศึกษา)* สาขาวิชา: ..............................................................
5. *(กรณีเป็นนักศึกษา)* ชั้นปีที่ศึกษา: ( ) ปี 1 ( ) ปี 2 ( ) ปี 3 ( ) ปี 4 ( ) อื่น ๆ
6. *(กรณีเป็นนักศึกษา)* ประเภทนักศึกษา: ( ) ภาคปกติ (เป้าหมาย 100 ชม.) ( ) ภาคพิเศษ (เป้าหมาย 50 ชม.)

## แบบประเมินหาค่าดัชนีความสอดคล้องของข้อคำถามกับวัตถุประสงค์งานวิจัย (IOC)

**เรื่อง** การพัฒนาเว็บแอปพลิเคชันเพื่อการบริหารจัดการและตรวจสอบผลการดำเนินกิจกรรมนักศึกษา มหาวิทยาลัยราชภัฏสุรินทร์ (สำหรับผู้เชี่ยวชาญ)

คำชี้แจง กรุณาใส่เครื่องหมาย ✓ ในข้อที่ท่านเห็นว่าตรงกับความเป็นจริง ที่ท่านสังเกตจากที่ได้พัฒนาขึ้น โดยมีเกณฑ์ดังนี้

ระดับ +1 หมายถึง แน่ใจว่ารายการประเมินสอดคล้องกับวัตถุประสงค์แบบประเมิน
ระดับ 0 หมายถึง ไม่แน่ใจว่ารายการประเมินสอดคล้องกับวัตถุประสงค์แบบประเมิน
ระดับ -1 หมายถึง แน่ใจว่ารายการประเมินไม่สอดคล้องกับวัตถุประสงค์แบบประเมิน
