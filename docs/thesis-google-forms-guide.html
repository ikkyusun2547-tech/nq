C ตอนที่ 2 — การประเมินประสิทธิภาพของระบบ
ใช้ประเภทคำถาม "Multiple choice grid" (ตารางหลายตัวเลือก) — คอลัมน์ (Columns) ใส่ 5, 4, 3, 2, 1 ทุกตาราง แล้วเปิด "ต้องกรอกคำตอบในแต่ละแถว" สร้างทั้งหมด 4 ตาราง ดังนี้
Grid 1 · หัวข้อตาราง
1. ด้านการทำงานของระบบ (Functional Requirement)
แถว (Rows) — 1 บรรทัดต่อ 1 แถว
ระบบสามารถตรวจสอบสิทธิ์และแยกการแสดงผลตามกลุ่มผู้ใช้งานได้ถูกต้อง ระบบสามารถสร้างกิจกรรม กำหนดโควตา และสร้าง QR Code ได้ ระบบสามารถบันทึกการเช็คชื่อเข้าร่วมกิจกรรมด้วย QR Code ร่วมกับ GPS และเซลฟีได้อย่างสมบูรณ์ ระบบสามารถเทียบโอนและแยกแยะเงื่อนไขชั่วโมงกิจกรรม (ภาคปกติ/พิเศษ) ได้
Grid 2 · หัวข้อตาราง
2. ด้านความถูกต้องของระบบ (Accuracy)
แถว
ความถูกต้องของการบันทึกข้อมูลลงฐานข้อมูลและการเรียกดูข้อมูลย้อนหลัง ความถูกต้องในการคำนวณและสรุปยอดชั่วโมงกิจกรรมสะสมของนักศึกษา ความถูกต้องของการแสดงผลลัพธ์การอนุมัติและการสร้างเอกสารสรุปผลกิจกรรม (PDF)
Grid 3 · หัวข้อตาราง
3. ด้านความง่ายในการใช้งาน (Usability)
แถว
การออกแบบส่วนติดต่อผู้ใช้งาน (User Interface) มีความเหมาะสม เข้าใจง่าย ลำดับขั้นตอนการทำงานของระบบมีความต่อเนื่อง ไม่ซับซ้อน ระบบมีการแจ้งเตือน (Error Message / Success Message) ที่ชัดเจน
Grid 4 · หัวข้อตาราง
4. ด้านความปลอดภัยของข้อมูล (Security)
แถว
ระบบมีการป้องกันการเข้าถึงข้อมูลจากผู้ที่ไม่มีสิทธิ์ได้อย่างรัดกุม ระบบมีการยืนยันตัวตนผ่านบัญชี Google ของมหาวิทยาลัยและจำกัดเฉพาะโดเมนที่กำหนดได้อย่างรัดกุม

Grid 1 · หัวข้อตาราง
1. ด้านการออกแบบและการแสดงผล (User Interface)
แถว

2. ด้านขั้นตอนการใช้งาน (Process)
แถว
ขั้นตอนการเข้าสู่ระบบด้วยบัญชี Google มีความสะดวกและรวดเร็ว การค้นหากิจกรรมที่สนใจและการเข้าร่วมกิจกรรมทำได้ง่าย ความสะดวกในการเช็คชื่อหน้างานผ่านการสแกน QR Code และถ่ายภาพยืนยันตัวตน ความง่ายในการยื่นคำขอเช็คชื่อย้อนหลังผ่านระบบ (กรณีพลาดเช็คชื่อ)

🚀 หลังสร้างฟอร์มเสร็จทั้ง 2 ฟอร์ม

  1. ส่งลิงก์: กด "ส่ง" (Send) มุมขวาบน → ไอคอนลิงก์ 🔗 → กด "ย่อ URL" ให้ได้ลิงก์สั้น → ส่งฟอร์มที่ 1 ให้ผู้เชี่ยวชาญ 5 ท่าน และฟอร์มที่ 2 ให้กลุ่มตัวอย่าง 28 คน (หลังให้ทดลองใช้เว็บ SRRU Check จริงก่อน)
  2. ดึงคำตอบเป็นตาราง: เปิดฟอร์ม → แท็บ "การตอบกลับ" (Responses) → กดไอคอน Sheets สีเขียวมุมขวาบน → ได้ตารางรวมคำตอบทั้งหมดอัตโนมัติ ไม่ต้องคีย์เอง
  3. คำนวณผล: ในตาราง Sheets ใช้สูตร =AVERAGE(ช่วงคอลัมน์) และ =STDEV.S(ช่วงคอลัมน์) ตามขั้นตอนที่อธิบายไว้ในบทที่ 4 หัวข้อ 4.2 และ 4.3 ของเอกสารหลัก
