## ภาพที่ 5 — ระบบตรวจสอบสิทธิ์และการเข้าสู่ระบบ (Login)

```plantuml
@startuml
|ผู้ใช้งาน|
start
:กดปุ่ม "เข้าสู่ระบบด้วย Google";
|Google|
:แสดงหน้ายืนยันตัวตน;
if (ยืนยันตัวตนสำเร็จ?) then (ไม่สำเร็จ)
  |ระบบ|
  :แสดงข้อความเข้าสู่ระบบไม่สำเร็จ;
  stop
else (สำเร็จ)
endif
|ระบบ|
if (อีเมลอยู่ในโดเมนมหาวิทยาลัย?) then (ไม่ใช่)
  :แสดงข้อความอนุญาตเฉพาะอีเมลมหาวิทยาลัย;
  stop
else (ใช่)
endif
if (บัญชีถูกระงับ?) then (ถูกระงับ)
  :แสดงข้อความบัญชีถูกระงับการใช้งาน;
  stop
else (ไม่ถูกระงับ)
endif
:สร้างหรืออัปเดตข้อมูลผู้ใช้งานอัตโนมัติ;
if (ตรวจสอบสิทธิ์ Role) then (admin/super_admin)
  :พาไปหน้า Dashboard ผู้ดูแลระบบ;
else (student)
  if (กรอกข้อมูลโปรไฟล์ครบถ้วน?) then (ยังไม่ครบ)
    :พาไปหน้ากรอกข้อมูลโปรไฟล์;
  else (ครบแล้ว)
    :พาไปหน้า Dashboard นักศึกษา;
  endif
endif
stop
@enduml
```

## ภาพที่ 6 — ระบบการสร้างและจัดการกิจกรรม

```plantuml
@startuml
|ผู้รับผิดชอบกิจกรรม|
start
:เปิดฟอร์มสร้างกิจกรรมใหม่;
:กรอกชื่อ รายละเอียด ระดับกิจกรรม
หมวดหมู่ ลักษณะกิจกรรม วันเวลา;
:ปักหมุดสถานที่จัดกิจกรรมบนแผนที่
และกำหนดรัศมีพื้นที่เช็คชื่อ;
|ระบบ|
if (ข้อมูลครบถ้วนถูกต้อง?) then (ไม่ถูกต้อง)
  :แสดงข้อความแจ้งเตือนให้แก้ไขข้อมูล;
  |ผู้รับผิดชอบกิจกรรม|
  backward:แก้ไขข้อมูล;
else (ถูกต้อง)
endif
|ระบบ|
:บันทึกกิจกรรมลงฐานข้อมูล;
:สร้างรหัสกิจกรรมและรหัสลับสำหรับ QR Code;
if (สถานะกิจกรรมเป็นเปิดรับสมัคร?) then (เปิดรับ)
  :แจ้งเตือนนักศึกษาที่มีสิทธิ์เข้าร่วม;
  |นักศึกษา|
  :ได้รับการแจ้งเตือน;
else (ร่าง/ไม่เปิดรับ)
  |ระบบ|
  :บันทึกเป็นฉบับร่าง;
endif
stop
@enduml
```

## ภาพที่ 7 — ระบบเรียกดูและเช็คชื่อเข้าร่วมกิจกรรม

```plantuml
@startuml
|นักศึกษา|
start
:เรียกดูรายการกิจกรรมที่ตนเองมีสิทธิ์เข้าร่วม;
:เลือกกิจกรรมที่ต้องการเข้าร่วม;
if (วิธีเช็คชื่อของกิจกรรมนี้) then (สแกน QR + GPS + เซลฟี)
  :สแกน QR Code หน้างาน;
  |ระบบ|
  if (QR Code ถูกต้องและยังไม่หมดอายุ?) then (ไม่ถูกต้อง)
    :แสดงข้อความ QR Code ไม่ถูกต้อง;
    stop
  else (ถูกต้อง)
  endif
  :ตรวจสอบตำแหน่ง GPS เทียบกับรัศมีที่กำหนด;
  |นักศึกษา|
  :ถ่ายภาพเซลฟียืนยันตัวตน;
  |ระบบ|
  :บันทึกผลการเช็คชื่อ;
  if (อยู่ในรัศมีและเงื่อนไขครบถ้วน?) then (ครบถ้วน)
    :สถานะ: อนุมัติอัตโนมัติ;
  else (ไม่ครบ/น่าสงสัย)
    :สถานะ: รอผู้ดูแลตรวจสอบ;
  endif
else (รายงานตนเอง)
  |นักศึกษา|
  :แนบรูปภาพหลักฐานและกรอกรายละเอียด;
  |ระบบ|
  :บันทึกคำร้อง สถานะ: รอตรวจสอบ
  (หรืออนุมัติอัตโนมัติตามที่กำหนด);
endif
stop
@enduml
```

## ภาพที่ 8 — ระบบยื่นคำขอเช็คชื่อย้อนหลัง

```plantuml
@startuml
|นักศึกษา|
start
:พบว่าพลาดการเช็คชื่อในช่วงเวลาที่กิจกรรมกำหนด;
:เปิดหน้ารายละเอียดกิจกรรม กดขอเช็คชื่อย้อนหลัง;
|ระบบ|
if (กิจกรรมนี้อนุญาตให้ขอย้อนหลัง?) then (ไม่อนุญาต)
  :แสดงข้อความไม่สามารถขอย้อนหลังได้;
  stop
else (อนุญาต)
endif

  :แสดงข้อความมีคำร้องค้างอยู่แล้ว;
  stop
else (ไม่มี)
endif
|นักศึกษา|
:กรอกเหตุผลและแนบรูปภาพหลักฐาน;
|ระบบ|
:บันทึกคำร้อง สถานะ: รอพิจารณา;
stop
@enduml
```

```plantuml
  stop
```

```plantuml
@enduml
```

## ภาพที่ 11 — ระบบการพิจารณาอนุมัติคำร้องต่าง ๆ

```plantuml
@startuml
|ผู้รับผิดชอบกิจกรรม|
start
:เปิดรายการรอตรวจสอบ;
switch (ประเภทรายการ)
case (เช็คชื่อ Flagged)
  :ตรวจสอบภาพเซลฟี ตำแหน่ง GPS และเวลา;
case (คำขอเช็คชื่อย้อนหลัง)
  :ตรวจสอบเหตุผลและหลักฐานที่แนบมา;
case (คำร้องเทียบโอนกิจกรรมภายนอก)
  :ตรวจสอบหลักฐานและกำหนดชั่วโมงที่อนุมัติจริง;
case (คำร้องเทียบโอนชั่วโมงตำแหน่ง)
  :ตรวจสอบหลักฐานการดำรงตำแหน่ง;
endswitch
if (ตัดสินใจ) then (อนุมัติ)
  :อัปเดตสถานะเป็นอนุมัติ
  บวกชั่วโมงเข้ายอดสะสม;
  |ระบบ|
  :แจ้งเตือนผลการอนุมัติให้นักศึกษาทราบ;
else (ปฏิเสธ)
  |ผู้รับผิดชอบกิจกรรม|
  :อัปเดตสถานะเป็นปฏิเสธพร้อมระบุเหตุผล;
  |ระบบ|
  :แจ้งเตือนผลการปฏิเสธให้นักศึกษาทราบ;
endif
stop
@enduml
```

## ภาพที่ 12 — ระบบสร้างเอกสารสรุปผลกิจกรรม

```plantuml
@startuml
|นักศึกษา|
start
:กดดาวน์โหลดเอกสารสรุปประวัติกิจกรรม;
|ระบบ|
:ดึงข้อมูลการเช็คชื่อที่ได้รับอนุมัติแล้วทั้งหมด;
:ดึงข้อมูลกิจกรรมภายนอกที่ได้รับอนุมัติแล้ว;
:ดึงข้อมูลการเทียบโอนชั่วโมงที่ได้รับอนุมัติแล้ว;
:รวมและเรียงลำดับตามวันที่เข้าร่วม;
:สร้างไฟล์เอกสารสรุปรูปแบบ PDF;
:ส่งไฟล์ให้นักศึกษาดาวน์โหลด;
|นักศึกษา|
:ดาวน์โหลดไฟล์ PDF;
stop
@enduml
```

## ภาพที่ 13 — ระบบเทียบโอนชั่วโมงกิจกรรมโดยตรง (Admin Grant)

```plantuml
@startuml
|ผู้รับผิดชอบกิจกรรม|
start
:ค้นหานักศึกษาด้วยรหัสนักศึกษา;
|ระบบ|
if (พบข้อมูลนักศึกษา?) then (ไม่พบ)
  :แสดงข้อความไม่พบข้อมูลนักศึกษา;
  stop
else (พบ)
endif
|ผู้รับผิดชอบกิจกรรม|
:เลือกตำแหน่งที่นักศึกษาดำรง
และปีการศึกษาที่เทียบโอน;
|ระบบ|
:แสดงจำนวนชั่วโมงมาตรฐานของตำแหน่งนั้นโดยอัตโนมัติ;
|ผู้รับผิดชอบกิจกรรม|
if (ยืนยันการเทียบโอน?) then (ยกเลิก)
  stop
else (ยืนยัน)
endif
|ระบบ|
:บันทึกประวัติการเทียบโอน สถานะ: อนุมัติทันที;
:บวกจำนวนชั่วโมงเข้ายอดสะสมของนักศึกษา;
stop
@enduml
```
