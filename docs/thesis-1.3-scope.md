## 1.3 ขอบเขตของการวิจัย

### 1.3.1 ขอบเขตของเว็บแอปพลิเคชัน

1.3.1.1 เป็นระบบเว็บแอปพลิเคชันที่สามารถเข้าถึงผ่านเว็บเบราว์เซอร์ โดยไม่จำเป็นต้องติดตั้งโปรแกรมเพิ่มเติม

1.3.1.2 รองรับการใช้งานบนอุปกรณ์หลากหลายประเภท ได้แก่ คอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ

1.3.1.3 ฟังก์ชันหลักของเว็บแอปพลิเคชัน ได้แก่

1. ระบบเข้าสู่ระบบและจัดการบัญชีผู้ใช้งานผ่านบัญชี Google ของมหาวิทยาลัย เพื่อรองรับการเข้าสู่ระบบและการกำหนดสิทธิ์การใช้งานตามบทบาทของผู้ใช้งาน (นักศึกษา ผู้ดูแลระบบ และผู้ดูแลระบบสูงสุด)

2. ระบบกรอกและแก้ไขข้อมูลโปรไฟล์นักศึกษา ได้แก่ ชื่อ-นามสกุล รหัสนักศึกษา คณะ สาขาวิชา ชั้นปี และประเภทหลักสูตร (ภาคปกติ/กศ.บป.)

3. ระบบเช็คชื่อเข้าร่วมกิจกรรมด้วยการสแกน QR Code ที่มีการเปลี่ยนรหัสอัตโนมัติตามช่วงเวลาเพื่อป้องกันการสวมสิทธิ์ ร่วมกับการตรวจสอบตำแหน่ง GPS และการถ่ายภาพเซลฟีเพื่อยืนยันตัวตน

4. ระบบเช็คชื่อแบบรายงานตนเองพร้อมแนบรูปภาพหลักฐาน สำหรับกิจกรรมที่ไม่สามารถสแกน QR Code หน้างานได้ โดยรอการตรวจสอบและอนุมัติจากผู้ดูแลระบบ (หรืออนุมัติอัตโนมัติได้ตามที่กำหนด)

5. ระบบขอเช็คชื่อย้อนหลัง สำหรับนักศึกษาที่พลาดการเช็คชื่อในช่วงเวลาที่กำหนด พร้อมระบบตรวจสอบและอนุมัติคำร้องโดยผู้ดูแลระบบ

6. ระบบบันทึกและคำนวณชั่วโมงกิจกรรมสะสมของนักศึกษา โดยแยกเกณฑ์ตามประเภทนักศึกษา (ภาคปกติ ไม่น้อยกว่า 25 กิจกรรม รวม 100 ชั่วโมง / ภาคพิเศษ ไม่น้อยกว่า 4 กิจกรรม รวม 50 ชั่วโมง) และสามารถกำหนดเกณฑ์แยกตามปีการศึกษาที่เข้าศึกษาของแต่ละรุ่นได้

7. ระบบจัดการหมวดหมู่กิจกรรม แบ่งตามด้าน 5 ด้าน (ทำนุบำรุงศิลปวัฒนธรรม, วิชาการ, กีฬาและส่งเสริมสุขภาพ, จิตอาสาและบำเพ็ญประโยชน์, คุณธรรมจริยธรรม) และลักษณะกิจกรรม 3 ประเภท (กิจกรรมบังคับแกน, กิจกรรมบังคับเลือก, กิจกรรมซ้อม/เตรียมงาน)

8. ระบบจัดการกิจกรรมสำหรับผู้ดูแลระบบ ได้แก่ การสร้าง/แก้ไข/ปิดกิจกรรม การกำหนดวันเวลา จำนวนรับ การปักหมุดสถานที่จัดกิจกรรมบนแผนที่พร้อมกำหนดรัศมีพื้นที่เช็คชื่อ และการจำกัดสิทธิ์ผู้เข้าร่วมตามคณะ/สาขา/ชั้นปี

9. ระบบตรวจสอบและแสดงสถานะความคืบหน้าของชั่วโมงกิจกรรมนักศึกษาแบบเรียลไทม์ ทั้งฝั่งนักศึกษาและผู้ดูแลระบบ

10. ระบบเทียบโอนชั่วโมงกิจกรรม (Credit Transfer) สำหรับนักศึกษาที่มีผลงานดีเด่น ผู้นำนักศึกษา หรือผู้ที่เป็นตัวแทนมหาวิทยาลัย โดยผู้ดูแลระบบสามารถกำหนดตำแหน่งและจำนวนชั่วโมงที่ได้รับต่อตำแหน่งได้เอง

11. ระบบยื่นคำร้องขอเทียบโอนชั่วโมงกิจกรรมภายนอกมหาวิทยาลัย พร้อมจำกัดจำนวนชั่วโมงสูงสุดต่อปีการศึกษา และระบบตรวจสอบ/อนุมัติคำร้องโดยผู้ดูแลระบบ

12. ระบบสร้างและดาวน์โหลดเอกสารสรุปประวัติการเข้าร่วมกิจกรรมและชั่วโมงกิจกรรมสะสมของนักศึกษาในรูปแบบไฟล์ PDF

13. ระบบรายงานสำหรับผู้ดูแลระบบและผู้บริหาร ได้แก่ รายงานสรุปการเข้าร่วมกิจกรรมแยกตามคณะ รายงานแยกตามหมวดหมู่กิจกรรม รายงานสถิติคำร้องต่าง ๆ รายงานสถานะการผ่านเกณฑ์ (Clearance) และรายงานนักศึกษากลุ่มเสี่ยงที่ยังไม่ผ่านเกณฑ์ก่อนจบการศึกษา พร้อมส่งออกเป็นไฟล์ Excel/PDF

14. ระบบนำเข้าและส่งออกข้อมูลนักศึกษาจำนวนมากด้วยไฟล์ Excel/CSV พร้อมไฟล์แม่แบบ (Template) สำหรับการนำเข้า

15. ระบบจัดการบัญชีผู้ใช้งานสำหรับผู้ดูแลระบบสูงสุด ได้แก่ การกำหนด/เปลี่ยนสิทธิ์การใช้งาน และการระงับ (ban) บัญชีผู้ใช้งาน

16. ระบบจัดการข้อมูลคณะและสาขาวิชาของมหาวิทยาลัย

17. ระบบประกาศข่าวสาร (Announcement) จากผู้ดูแลระบบถึงนักศึกษา โดยสามารถเลือกกลุ่มเป้าหมายตามคณะได้

18. ระบบแจ้งเตือน ทั้งการแจ้งเตือนภายในระบบ การแจ้งเตือนแบบ Push Notification บนเบราว์เซอร์/อุปกรณ์มือถือ และการแจ้งเตือนทางอีเมล

19. ระบบติดต่อสื่อสารระหว่างนักศึกษาและผู้ดูแลระบบ (Contact/แชท) แบบแยกกระทู้ตามเรื่อง พร้อมแนบไฟล์/รูปภาพได้

20. ระบบบันทึกประวัติการดำเนินการของผู้ดูแลระบบ (Audit Log) รวมทุกการอนุมัติ/ปฏิเสธคำร้อง การเปลี่ยนสิทธิ์ผู้ใช้งาน และการแก้ไขข้อมูลตั้งต้นของระบบ ไว้ในที่เดียวเพื่อการตรวจสอบย้อนหลัง

### 1.3.2 ขอบเขตด้านกลุ่มผู้ใช้

#### 1.3.2.1 ขอบเขตการใช้งานของนักศึกษา

1. สามารถเข้าสู่ระบบเว็บแอปพลิเคชันด้วยบัญชี Google ของมหาวิทยาลัย

2. สามารถเพิ่ม แก้ไข และเรียกดูข้อมูลส่วนตัวของตนเองได้

3. สามารถเรียกดูข้อมูลชั่วโมงกิจกรรมที่ตนเองเข้าร่วมได้ โดยระบบจะแสดงผลเป้าหมายชั่วโมงตามประเภทนักศึกษา (ภาคปกติ/ภาคพิเศษ)

4. สามารถลงทะเบียนการเข้าร่วมกิจกรรม อัปโหลดหลักฐาน และสแกนเช็คชื่อผ่านระบบ

5. สามารถดาวน์โหลดเอกสารสรุปประวัติการเข้าร่วมกิจกรรมและชั่วโมงกิจกรรมสะสมในรูปแบบไฟล์ PDF ได้ตลอดเวลา ไม่จำเพาะว่าต้องสะสมครบตามเกณฑ์ก่อน

6. สามารถยื่นคำขอเช็คชื่อย้อนหลัง กรณีพลาดการเช็คชื่อในช่วงเวลาที่กำหนดของกิจกรรมนั้น ได้โดยตรงผ่านหน้าเว็บรายละเอียดกิจกรรม

#### 1.3.2.2 ขอบเขตผู้รับผิดชอบกิจกรรมกองพัฒนานักศึกษา

1. สามารถเข้าสู่ระบบผ่านเว็บแอปพลิเคชันด้วยบัญชีผู้ใช้งานที่ได้รับสิทธิ์

2. สามารถสร้าง แก้ไข และกำหนดรายละเอียดกิจกรรมได้ (เช่น วันเวลา, หมวดหมู่กิจกรรม 5 ด้าน, ลักษณะกิจกรรม 3 ประเภท คือ กิจกรรมบังคับแกน กิจกรรมบังคับเลือก และกิจกรรมซ้อม/เตรียมงาน, จำนวนชั่วโมง)

3. สามารถจัดการรายชื่อ จัดการ QR Code สำหรับเช็คชื่อ และบันทึกการเข้าร่วมของนักศึกษา

4. สามารถตรวจสอบ อนุมัติชั่วโมงกิจกรรมของนักศึกษา และพิจารณาอนุมัติคำขอเช็คชื่อย้อนหลังจากนักศึกษาได้

5. สามารถเรียกดูและดาวน์โหลดรายงานสรุปผลการดำเนินกิจกรรมและรายงานชั่วโมงกิจกรรมของนักศึกษา

6. สามารถใช้เมนู "เทียบโอนชั่วโมงกิจกรรม" เพื่อเพิ่มชั่วโมงพิเศษให้แก่นักศึกษาที่เป็นคณะกรรมการหรือผู้นำนักศึกษาได้โดยตรง
