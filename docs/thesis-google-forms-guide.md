# คู่มือสร้าง Google Forms สำหรับเก็บข้อมูลวิจัย

คู่มือนี้บอกทีละขั้นตอนว่าจะสร้าง Google Forms 2 ฟอร์มยังไง (ฉบับที่ 1 สำหรับผู้เชี่ยวชาญ 5 ท่าน, ฉบับที่ 2 สำหรับกลุ่มตัวอย่างผู้ใช้งาน 28 คน) โดยคัดลอกข้อความจากคู่มือนี้ไปวางใน Google Forms ได้เลย ไม่ต้องคิดคำถามเอง

**ก่อนเริ่ม:** ไปที่ [forms.google.com](https://forms.google.com) → กด "ว่างเปล่า" (Blank) เพื่อเริ่มฟอร์มใหม่

---

## ฟอร์มที่ 1 — แบบประเมินประสิทธิภาพระบบ (ผู้เชี่ยวชาญ 5 ท่าน)

**ชื่อฟอร์ม (คลิกที่ "แบบฟอร์มไม่มีชื่อ" ด้านบน):**
```
แบบประเมินประสิทธิภาพระบบเว็บแอปพลิเคชัน SRRU Check
```

**คำอธิบายฟอร์ม (ช่องใต้ชื่อ):**
```
แบบประเมินนี้จัดทำขึ้นเพื่อประเมินประสิทธิภาพของระบบเว็บแอปพลิเคชันเพื่อการบริหารจัดการและตรวจสอบผลการดำเนินกิจกรรมนักศึกษา มหาวิทยาลัยราชภัฏสุรินทร์ โปรดประเมินตามความคิดเห็นของท่านมากที่สุด (5 = มากที่สุด, 1 = น้อยที่สุด)
```

### ส่วนที่ 1 — ข้อมูลทั่วไปของผู้เชี่ยวชาญ

กด "เพิ่มส่วน" (ไอคอนเส้นคู่ด้านขวา) เพื่อขึ้นส่วนใหม่ ตั้งชื่อส่วนว่า **"ตอนที่ 1 ข้อมูลทั่วไปของผู้เชี่ยวชาญ"** แล้วเพิ่มคำถาม:

**คำถาม 1** — ประเภทคำถาม: **Multiple choice**
```
ตำแหน่ง/ความเชี่ยวชาญ
```
ตัวเลือก: `นักวิเคราะห์ระบบ` / `นักพัฒนาซอฟต์แวร์` / `ผู้ดูแลระบบฐานข้อมูล` / `อาจารย์ผู้สอนด้านคอมพิวเตอร์` / เปิด "เพิ่มตัวเลือกอื่นๆ" (Add "Other")

**คำถาม 2** — ประเภทคำถาม: **Short answer**
```
ประสบการณ์การทำงานด้านเทคโนโลยีสารสนเทศ (ปี)
```

### ส่วนที่ 2 — การประเมินประสิทธิภาพของระบบ

เพิ่มส่วนใหม่ ชื่อ **"ตอนที่ 2 การประเมินประสิทธิภาพของระบบเว็บแอปพลิเคชัน"**

ใช้ประเภทคำถาม **"Multiple choice grid"** (ตารางหลายตัวเลือก) — สร้าง 4 คำถามแบบตาราง (1 ตารางต่อ 1 ด้าน) ดังนี้ สำหรับแต่ละตาราง: **แถว (Rows)** = ข้อย่อย, **คอลัมน์ (Columns)** = `5`, `4`, `3`, `2`, `1` — แล้วเปิด "ต้องกรอกคำตอบในแต่ละแถว" (Require a response in each row)

**ตารางที่ 1 — หัวข้อ:** `1. ด้านการทำงานของระบบ (Functional Requirement)`
แถว:
```
ระบบสามารถตรวจสอบสิทธิ์และแยกการแสดงผลตามกลุ่มผู้ใช้งานได้ถูกต้อง
ระบบสามารถสร้างกิจกรรม กำหนดโควตา และสร้าง QR Code ได้
ระบบสามารถบันทึกการเช็คชื่อเข้าร่วมกิจกรรมด้วย QR Code ร่วมกับ GPS และเซลฟีได้อย่างสมบูรณ์
ระบบสามารถเทียบโอนและแยกแยะเงื่อนไขชั่วโมงกิจกรรม (ภาคปกติ/พิเศษ) ได้
```

**ตารางที่ 2 — หัวข้อ:** `2. ด้านความถูกต้องของระบบ (Accuracy)`
แถว:
```
ความถูกต้องของการบันทึกข้อมูลลงฐานข้อมูลและการเรียกดูข้อมูลย้อนหลัง
ความถูกต้องในการคำนวณและสรุปยอดชั่วโมงกิจกรรมสะสมของนักศึกษา
ความถูกต้องของการแสดงผลลัพธ์การอนุมัติและการสร้างเอกสารสรุปผลกิจกรรม (PDF)
```

**ตารางที่ 3 — หัวข้อ:** `3. ด้านความง่ายในการใช้งาน (Usability)`
แถว:
```
การออกแบบส่วนติดต่อผู้ใช้งาน (User Interface) มีความเหมาะสม เข้าใจง่าย
ลำดับขั้นตอนการทำงานของระบบมีความต่อเนื่อง ไม่ซับซ้อน
ระบบมีการแจ้งเตือน (Error Message / Success Message) ที่ชัดเจน
```

**ตารางที่ 4 — หัวข้อ:** `4. ด้านความปลอดภัยของข้อมูล (Security)`
แถว:
```
ระบบมีการป้องกันการเข้าถึงข้อมูลจากผู้ที่ไม่มีสิทธิ์ได้อย่างรัดกุม
ระบบมีการยืนยันตัวตนผ่านบัญชี Google ของมหาวิทยาลัยและจำกัดเฉพาะโดเมนที่กำหนดได้อย่างรัดกุม
```

### ส่วนที่ 3 — ข้อเสนอแนะเพิ่มเติม

เพิ่มส่วนใหม่ ชื่อ **"ตอนที่ 3 ข้อเสนอแนะเพิ่มเติม"** แล้วเพิ่มคำถามประเภท **Paragraph**:
```
ข้อเสนอแนะเพิ่มเติม (ถ้ามี)
```
ตั้งเป็น "ไม่บังคับตอบ" (ปิด Required)

## ฟอร์มที่ 2 — แบบสอบถามความพึงพอใจ (กลุ่มตัวอย่างผู้ใช้งาน 28 คน)

สร้างฟอร์มใหม่อีกฟอร์ม (อย่ารวมกับฟอร์มที่ 1)

**ชื่อฟอร์ม:**
```
แบบสอบถามความพึงพอใจต่อระบบ SRRU Check
```

**คำอธิบายฟอร์ม:**
```
แบบสอบถามนี้มีวัตถุประสงค์เพื่อประเมินความพึงพอใจในการใช้งานเว็บแอปพลิเคชันบริหารจัดการกิจกรรมนักศึกษา มหาวิทยาลัยราชภัฏสุรินทร์ โปรดตอบตามความเป็นจริงมากที่สุด (5 = มากที่สุด, 1 = น้อยที่สุด)
```

### ส่วนที่ 1 — ข้อมูลทั่วไปของผู้ตอบแบบสอบถาม

**คำถาม 1** — **Multiple choice**
```
บทบาท
```
ตัวเลือก: `นักศึกษา` / `อาจารย์ประจำกองพัฒนานักศึกษา` / `ผู้แทนสภานักศึกษา`

> 💡 เคล็ดลับ: กดจุด 3 จุดมุมขวาล่างของคำถามนี้ → เลือก **"ไปยังส่วนตามคำตอบ"** (Go to section based on answer) — ถ้าตอบ "นักศึกษา" ให้ไปส่วนที่ 1ข (มีคำถามคณะ/สาขา) ถ้าตอบอย่างอื่นให้ข้ามไปส่วนที่ 2 เลย จะได้ไม่ต้องบังคับอาจารย์/สภานักศึกษาตอบคำถามที่ไม่เกี่ยวกับตัวเอง

**คำถาม 2** — **Multiple choice**
```
เพศ
```
ตัวเลือก: `ชาย` / `หญิง` / เปิด "เพิ่มตัวเลือกอื่นๆ"

**ส่วนที่ 1ข (เฉพาะนักศึกษา)** — เพิ่มส่วนใหม่ชื่อ **"ข้อมูลเพิ่มเติม (เฉพาะผู้ตอบที่เป็นนักศึกษา)"**:

**คำถาม 3** — **Short answer**: `คณะ`
**คำถาม 4** — **Short answer**: `สาขาวิชา`
**คำถาม 5** — **Multiple choice**: `ชั้นปีที่ศึกษา` — ตัวเลือก `ปี 1` `ปี 2` `ปี 3` `ปี 4` + เพิ่มตัวเลือกอื่นๆ
**คำถาม 6** — **Multiple choice**: `ประเภทนักศึกษา` — ตัวเลือก `ภาคปกติ (เป้าหมาย 100 ชม.)` / `ภาคพิเศษ (เป้าหมาย 50 ชม.)`

### ส่วนที่ 2 — ความพึงพอใจที่มีต่อการใช้งานระบบ

ใช้ **Multiple choice grid** เหมือนฟอร์มที่ 1 (คอลัมน์ = `5` `4` `3` `2` `1`, เปิด Require a response in each row)

**ตารางที่ 1 — หัวข้อ:** `1. ด้านการออกแบบและการแสดงผล (User Interface)`
```
รูปแบบหน้าจอมีความสวยงาม ทันสมัย และอ่านข้อมูลได้ง่าย
การจัดวางเมนูและปุ่มคำสั่งต่าง ๆ มีความเป็นระเบียบและค้นหาง่าย
ระบบสามารถแสดงผลบนโทรศัพท์มือถือและคอมพิวเตอร์ได้อย่างเหมาะสม
```

**ตารางที่ 2 — หัวข้อ:** `2. ด้านขั้นตอนการใช้งาน (Process)`
```
ขั้นตอนการเข้าสู่ระบบด้วยบัญชี Google มีความสะดวกและรวดเร็ว
การค้นหากิจกรรมที่สนใจและการเข้าร่วมกิจกรรมทำได้ง่าย
ความสะดวกในการเช็คชื่อหน้างานผ่านการสแกน QR Code และถ่ายภาพยืนยันตัวตน
ความง่ายในการยื่นคำขอเช็คชื่อย้อนหลังผ่านระบบ (กรณีพลาดเช็คชื่อ)
```

**ตารางที่ 3 — หัวข้อ:** `3. ด้านประโยชน์ที่ได้รับ (Benefits)`
```
ระบบช่วยให้นักศึกษาสามารถตรวจสอบชั่วโมงสะสมของตนเองได้แบบเรียลไทม์
ระบบช่วยลดความผิดพลาดและป้องกันข้อมูลชั่วโมงกิจกรรมสูญหาย
การดาวน์โหลดเอกสารสรุปผลกิจกรรมแบบ PDF ผ่านระบบมีความสะดวกมากกว่าการขอเอกสารแบบเดิม
ภาพรวมท่านมีความพึงพอใจต่อระบบเว็บแอปพลิเคชันนี้ในระดับใด
```

### ส่วนที่ 3 — ข้อเสนอแนะเพิ่มเติม

เพิ่มคำถามประเภท **Paragraph** (ไม่บังคับตอบ):
```
ข้อเสนอแนะเพิ่มเติมเพื่อการพัฒนาระบบ (ถ้ามี)
```

## หลังสร้างฟอร์มเสร็จ

1. กดไอคอน **สี** (จานสี มุมขวาบน) เลือกธีมสีให้เข้ากับมหาวิทยาลัยได้ตามชอบ — ไม่จำเป็น แค่เสริมความสวยงาม
2. กด **"ส่ง" (Send)** มุมขวาบน → กดไอคอน **ลิงก์ (🔗)** → กด "ย่อ URL" (Shorten URL) จะได้ลิงก์สั้นๆ ส่งได้ง่าย
3. ส่งลิงก์ฟอร์มที่ 1 ให้ผู้เชี่ยวชาญ 5 ท่านทางอีเมล/ไลน์ ส่งลิงก์ฟอร์มที่ 2 ให้กลุ่มตัวอย่าง 28 คน (หลังให้เขาทดลองใช้เว็บ SRRU Check จริงก่อน)
4. ดูคำตอบที่ส่งเข้ามา: เปิดฟอร์ม → แท็บ **"การตอบกลับ" (Responses)** → กดไอคอนสีเขียว (Google Sheets) มุมขวาบนของแท็บนั้น → จะสร้างชีตรวบรวมคำตอบทั้งหมดให้อัตโนมัติ ไม่ต้องคีย์เอง
5. จากชีตนั้น ใช้สูตร `=AVERAGE(ช่วงคอลัมน์)` และ `=STDEV.S(ช่วงคอลัมน์)` คำนวณตามขั้นตอนที่อธิบายไว้ในบทที่ 4 (หัวข้อ 4.2 และ 4.3)
