SRRU Check

คู่มือพรีเซนต์ระบบ

ลำดับหน้าที่ต้องโชว์ พร้อมสรุปว่าแต่ละหน้าทำอะไรได้บ้าง มีปุ่ม/ฟีเจอร์อะไร — ใช้เป็นแนวเวลาเดโมสด พูดเองตามธรรมชาติได้เลย

⏱ เวลารวมประมาณ 13-15 นาที
บทนำ30 วิ
มุมมองนักศึกษา~5 นาที
มุมมองผู้รับผิดชอบกิจกรรม~4 นาที
มุมมองผู้ดูแลระบบ~3 นาที
สรุปปิดท้าย~1 นาที

✅ เตรียมก่อนเริ่มพรีเซนต์ (ทำล่วงหน้า 1 วันก่อนสอบ)

  • เตรียม 3 บัญชีทดสอบ — 1 บัญชีนักศึกษา, 1 บัญชีผู้รับผิดชอบกิจกรรม, 1 บัญชีผู้ดูแลระบบ (ล็อกอินไว้ล่วงหน้าคนละอุปกรณ์/เบราว์เซอร์ จะได้ไม่ต้องสลับล็อกอินสดหน้ากรรมการ)
  • สร้างกิจกรรมทดสอบ 1 รายการไว้ล่วงหน้า ที่ยัง "เปิดรับ" อยู่ พร้อมพิกัดตรงกับสถานที่สอบจริง (หรือตั้งรัศมีให้กว้างพอ) จะได้เดโมเช็คชื่อได้จริงสด ๆ
  • เปิดสิทธิ์กล้อง/ตำแหน่ง (GPS) ของเบราว์เซอร์ไว้ล่วงหน้า ในอุปกรณ์ที่จะใช้เดโม กันไม่ให้ popup ขอสิทธิ์ขึ้นกวนตอนพรีเซนต์สด
  • เตรียมมือถือ 1 เครื่อง + คอมพิวเตอร์/โน้ตบุ๊ก 1 เครื่อง เปิดพร้อมกัน — มือถือใช้โชว์ฝั่งนักศึกษา (เช็คชื่อ) คอมใช้โชว์ฝั่งผู้รับผิดชอบกิจกรรม/ผู้ดูแลระบบ (ตาราง รายงาน)
  • เช็กอินเทอร์เน็ตของสถานที่สอบล่วงหน้า ระบบต้องใช้เน็ตตลอดการเดโม (เป็นเว็บแอป ไม่มีโหมดออฟไลน์)
เริ่มต้น

บทนำ

30 วินาที
•แนะนำระบบสั้น ๆ ก่อนเข้าเดโม
พูดถึง
  • ชื่อระบบ SRRU Check — เว็บแอปบริหารจัดการและตรวจสอบชั่วโมงกิจกรรมนักศึกษา ม.ราชภัฏสุรินทร์
  • ปัญหาเดิม: ใช้เอกสารกระดาษ ตรวจสอบด้วยมือ ล่าช้า
  • ทางแก้: เช็คชื่อผ่าน QR+GPS+เซลฟี, ติดตามชั่วโมงเรียลไทม์, จัดการคำร้อง/รายงานผ่านระบบทั้งหมด
Act 1 — นักศึกษา

มุมมองนักศึกษา

~5 นาที
1หน้าเข้าสู่ระบบ (Login)มือถือ
ทำอะไรได้ / มีอะไร
  • ปุ่ม "เข้าสู่ระบบด้วย Google" ปุ่มเดียว ไม่มีช่องกรอกรหัสผ่าน
  • ระบบตรวจสอบโดเมนอีเมลอัตโนมัติ อนุญาตเฉพาะ @srru.ac.th
  • ไม่มีหน้าสมัครสมาชิกแยก — บัญชีถูกสร้างอัตโนมัติตอนล็อกอินครั้งแรก
2แดชบอร์ดนักศึกษามือถือ
ทำอะไรได้ / มีอะไร
  • แสดง ชั่วโมงสะสมเทียบเป้าหมายแบบเรียลไทม์ (ภาคปกติ 100 ชม. / ภาคพิเศษ 50 ชม.)
  • แถบ/กราฟความคืบหน้า อัปเดตทันทีที่คำร้องได้รับอนุมัติ
  • รายการประวัติกิจกรรมที่เข้าร่วมล่าสุด
3รายการกิจกรรม → เช็คชื่อเข้าร่วมกิจกรรมมือถือ
ทำอะไรได้ / มีอะไร
  • ตัวกรองกิจกรรมตาม หมวดหมู่ / ระดับกิจกรรม / ปีการศึกษา
  • ปุ่ม สแกน QR Code — รหัสเปลี่ยนอัตโนมัติตามช่วงเวลา กันแคปภาพไปให้คนอื่นสแกนแทน
  • ตรวจสอบ ตำแหน่ง GPS เทียบกับรัศมีที่กิจกรรมกำหนดไว้ อัตโนมัติ
  • ปุ่ม ถ่ายภาพเซลฟี ยืนยันตัวตนก่อนบันทึกผล
  • ทางเลือก "รายงานตนเอง" พร้อมแนบรูปหลักฐาน — สำหรับกิจกรรมที่สแกน QR หน้างานไม่ได้
ถ้าสแกนสดไม่ได้ (เน็ตช้า/แสงไม่พอ) เตรียม screenshot/วิดีโอสำรองไว้เผื่อสถานการณ์ฉุกเฉิน
4ยื่นคำขอเช็คชื่อย้อนหลัง / เทียบโอนชั่วโมงมือถือ
ทำอะไรได้ / มีอะไร
  • ยื่นคำขอเช็คชื่อย้อนหลัง — กรอกเหตุผล + แนบรูปหลักฐาน กรณีพลาดสแกนในเวลาที่กำหนด
  • ยื่นคำร้องเทียบโอนชั่วโมงกิจกรรมภายนอก — กรอกรายละเอียด+แนบหลักฐาน จำกัดสูงสุด 10 ชั่วโมง/ปีการศึกษา
  • ยื่นคำร้องเทียบโอนชั่วโมงตำแหน่ง — สำหรับนักศึกษาที่ดำรงตำแหน่งในองค์กรนักศึกษา ระบบคำนวณชั่วโมงมาตรฐานของตำแหน่งให้อัตโนมัติ
5ดาวน์โหลดเอกสารสรุปผลกิจกรรม (PDF)มือถือ/คอม
ทำอะไรได้ / มีอะไร
  • ปุ่ม ดาวน์โหลด PDF — สรุปประวัติกิจกรรมและชั่วโมงสะสมทั้งหมด ได้ทันทีไม่ต้องรอเจ้าหน้าที่ออกเอกสารให้
Act 2 — เจ้าหน้าที่

มุมมองผู้รับผิดชอบกิจกรรม

~4 นาที
1สร้างและจัดการกิจกรรมคอม
ทำอะไรได้ / มีอะไร
  • ฟอร์มกรอก ชื่อ/รายละเอียด/ระดับกิจกรรม/หมวดหมู่ 5 ด้าน/ลักษณะกิจกรรม 3 ประเภท/วันเวลา/จำนวนรับ
  • ปักหมุดสถานที่บนแผนที่ + กำหนดรัศมีพื้นที่ที่อนุญาตให้เช็คชื่อ (ค่านี้คือสิ่งที่ใช้ตรวจ GPS ตอนนักศึกษาเช็คชื่อ)
  • แก้ไข/ปิดกิจกรรมที่สร้างไว้แล้วได้
2ตรวจสอบและอนุมัติคำร้องคอม
ทำอะไรได้ / มีอะไร
  • รวมคำร้องทุกประเภทไว้หน้าเดียว: เช็คชื่อสถานะรอตรวจสอบ (Flagged), คำขอเช็คชื่อย้อนหลัง, คำร้องเทียบโอนชั่วโมง
  • ปุ่ม อนุมัติ / ปฏิเสธ พร้อมดูรูปหลักฐาน/เซลฟี/ตำแหน่งที่แนบมา
  • อนุมัติแล้วระบบบวกชั่วโมงเข้ายอดสะสมอัตโนมัติทันที
3เทียบโอนชั่วโมงกิจกรรมโดยตรงคอม
ทำอะไรได้ / มีอะไร
  • ค้นหานักศึกษาด้วยรหัสนักศึกษา
  • เลือกตำแหน่งที่ดำรง → ระบบคำนวณชั่วโมงมาตรฐานให้อัตโนมัติ → บันทึกอนุมัติทันที (ไม่ต้องรอนักศึกษายื่นคำร้อง)
4รายงานคอม
ทำอะไรได้ / มีอะไร
  • รายงานสรุปการเข้าร่วมกิจกรรมแยกตามคณะ
  • รายงานชั่วโมงสะสมแยกตามหมวดหมู่ 5 ด้าน
  • รายงานสถิติคำร้องต่าง ๆ
  • รายงานนักศึกษากลุ่มเสี่ยง ที่ยังสะสมชั่วโมงไม่ครบเกณฑ์ก่อนจบการศึกษา
  • ปุ่ม ส่งออก Excel / PDF
5ประกาศข่าวสาร / ติดต่อนักศึกษาคอม
ทำอะไรได้ / มีอะไร
  • ส่งประกาศข่าวสารถึงนักศึกษา เลือกกลุ่มเป้าหมายตามคณะได้
  • ระบบติดต่อสื่อสารกับนักศึกษาแบบแยกกระทู้ตามเรื่อง
Act 3 — ผู้ดูแลระบบ

มุมมองผู้ดูแลระบบ

~3 นาที
1จัดการบัญชีผู้ใช้งานคอม
ทำอะไรได้ / มีอะไร
  • กำหนด/เปลี่ยนสิทธิ์การใช้งาน — 3 ระดับ: นักศึกษา, ผู้รับผิดชอบกิจกรรม, ผู้ดูแลระบบ
  • ปุ่ม ระงับ / ยกเลิกการระงับ บัญชีผู้ใช้งาน
2จัดการข้อมูลพื้นฐาน (Master Data)คอม
ทำอะไรได้ / มีอะไร
  • เพิ่ม/แก้ไข ข้อมูลคณะและสาขาวิชา
  • กำหนดตำแหน่งสำหรับเทียบโอนชั่วโมง และจำนวนชั่วโมงมาตรฐานของแต่ละตำแหน่ง
  • ตั้งเกณฑ์จำนวนกิจกรรม/ชั่วโมงที่ใช้ประเมินนักศึกษาแต่ละรุ่น (ไม่ต้องแก้โค้ด)
3ประวัติการดำเนินการ (Audit Log)คอม
ทำอะไรได้ / มีอะไร
  • บันทึกทุกการอนุมัติ/ปฏิเสธคำร้อง และการแก้ไขข้อมูลพื้นฐาน — ใครทำ อะไร เมื่อไหร่
  • ตรวจสอบย้อนหลังได้ทั้งหมดในหน้าเดียว เพิ่มความโปร่งใส
4นำเข้าข้อมูลนักศึกษาจำนวนมากคอม
ทำอะไรได้ / มีอะไร
  • อัปโหลดไฟล์ Excel/CSV นำเข้าข้อมูลนักศึกษาทีละหลายคน
  • มีไฟล์แม่แบบ (Template) ให้ดาวน์โหลดไปกรอกก่อนอัปโหลด
ปิดท้าย

สรุปปิดท้าย

~1 นาที
•สรุปจุดเด่นรวม
พูดถึง
  • เช็คชื่อป้องกันสวมสิทธิ์ด้วย 3 ชั้น: QR หมุนรหัส + GPS + เซลฟี
  • ติดตามชั่วโมงสะสมแบบเรียลไทม์ ทั้งฝั่งนักศึกษาและเจ้าหน้าที่
  • ระบบรายงาน/แจ้งเตือนกลุ่มเสี่ยง ช่วยเจ้าหน้าที่ทำงานเร็วขึ้น
  • ใช้งานได้ทั้งคอมพิวเตอร์และมือถือ — พัฒนาด้วย Laravel + MySQL, ทดลองใช้งานจริงบน Railway แล้ว

🎤 คำถามที่กรรมการมักถาม (เตรียมคำตอบไว้ล่วงหน้า)

ถ้านักศึกษาปลอมตำแหน่ง GPS ได้ไหม ป้องกันยังไง
ระบบใช้ 3 ชั้นร่วมกัน (QR ที่เปลี่ยนรหัสอัตโนมัติ + ตำแหน่ง GPS + เซลฟียืนยันตัวตน) ลดความเสี่ยงได้มากเมื่อเทียบกับการเช็คชื่อแบบเดิม แต่ยอมรับตรงๆ ว่าไม่มีระบบไหนป้องกันการปลอม GPS ได้ 100% หากเช็คชื่อที่ระบบตั้งค่าสถานะรอตรวจสอบ (Flagged) เจ้าหน้าที่จะตรวจสอบภาพเซลฟีและตำแหน่งอีกชั้นก่อนอนุมัติ
ทำไมเลือกทำเว็บแอปแทนที่จะทำแอปมือถือ (Native App)
เว็บแอปเข้าถึงได้ทันทีผ่านเบราว์เซอร์ ไม่ต้องติดตั้งหรือดาวน์โหลดจาก App Store/Play Store ลดอุปสรรคการใช้งาน และรองรับทั้งคอมพิวเตอร์และมือถือในโค้ดชุดเดียว ในข้อเสนอแนะของงานวิจัยก็ระบุไว้ว่าควรพัฒนาเป็น Native Mobile Application ในอนาคตเพื่อประสบการณ์ใช้งานที่ดียิ่งขึ้น โดยเฉพาะการแจ้งเตือนและการเข้าถึงกล้อง/GPS
การเทียบโอนชั่วโมงกิจกรรมภายนอกมีข้อจำกัดไหม
มีการจำกัดจำนวนชั่วโมงสูงสุดจากกิจกรรมภายนอกมหาวิทยาลัยไว้ที่ 10 ชั่วโมงต่อปีการศึกษา เพื่อไม่ให้ชั่วโมงสะสมพึ่งพากิจกรรมภายนอกมากเกินไป
ระบบมีมาตรการความปลอดภัยของข้อมูลอย่างไรบ้าง
ยืนยันตัวตนผ่าน Google OAuth จำกัดเฉพาะโดเมนอีเมลมหาวิทยาลัย ไม่มีรหัสผ่านให้ถูกขโมย มีระบบสิทธิ์การใช้งาน 3 ระดับ (Role-Based Access Control) และมี Audit Log บันทึกทุกการเปลี่ยนแปลงข้อมูลสำคัญ
