# Activity Diagram ทั้ง 9 ระบบงานหลัก (แบบ Swimlane — Mermaid)

PlantUML server สาธารณะไม่รองรับฟอนต์ภาษาไทย (ขึ้นเป็นกล่องสี่เหลี่ยม/ตัวอักษรขาดหาย) จึงกลับมาใช้ Mermaid ซึ่งเรนเดอร์ภาษาไทยได้ปกติ โดยจำลอง Swimlane ด้วย `subgraph` แยกคอลัมน์ตามผู้รับผิดชอบแต่ละขั้นตอน — วางโค้ดแต่ละอันที่ https://mermaid.live แล้ว export เป็นรูปภาพเพื่อนำไปแปะแทนภาพที่ 5-13

## ภาพที่ 5 — ระบบตรวจสอบสิทธิ์และการเข้าสู่ระบบ (Login)

```mermaid
flowchart LR
    subgraph L1["ผู้ใช้งาน"]
    direction TB
    A1([เริ่มต้น]) --> A2[กดปุ่มเข้าสู่ระบบด้วย Google]
    end
    subgraph L2["Google"]
    direction TB
    B1[แสดงหน้ายืนยันตัวตน]
    end
    subgraph L3["ระบบ"]
    direction TB
    C1{ยืนยันตัวตนสำเร็จ?}
    C2[แสดงข้อความ<br/>เข้าสู่ระบบไม่สำเร็จ]
    C3{อีเมลอยู่ในโดเมน<br/>มหาวิทยาลัย?}
    C4[แสดงข้อความ<br/>อนุญาตเฉพาะอีเมลมหาวิทยาลัย]
    C5{บัญชีถูกระงับ?}
    C6[แสดงข้อความ<br/>บัญชีถูกระงับการใช้งาน]
    C7[สร้างหรืออัปเดต<br/>ข้อมูลผู้ใช้งานอัตโนมัติ]
    C8{ตรวจสอบสิทธิ์ Role}
    C9[พาไปหน้า Dashboard<br/>ผู้ดูแลระบบ]
    C10{กรอกข้อมูลโปรไฟล์<br/>ครบถ้วนหรือยัง}
    C11[พาไปหน้า<br/>กรอกข้อมูลโปรไฟล์]
    C12[พาไปหน้า Dashboard<br/>นักศึกษา]
    End1([สิ้นสุด])
    end

    A2 --> B1
    B1 --> C1
    C1 -- ไม่สำเร็จ --> C2 --> End1
    C1 -- สำเร็จ --> C3
    C3 -- ไม่ใช่ --> C4 --> End1
    C3 -- ใช่ --> C5
    C5 -- ถูกระงับ --> C6 --> End1
    C5 -- ไม่ถูกระงับ --> C7 --> C8
    C8 -- admin/super_admin --> C9 --> End1
    C8 -- student --> C10
    C10 -- ยังไม่ครบ --> C11 --> End1
    C10 -- ครบแล้ว --> C12 --> End1
```
